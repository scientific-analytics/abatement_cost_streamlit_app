# Abatement Cost Analysis

Interactive Streamlit tool for analyzing how carbon pricing drives technology adoption in emission-intensive sectors.

## Features
- Define up to 3 decarbonization technologies with custom parameters
- Single facility analysis: calculate carbon price thresholds for technology adoption
- Sector analysis: simulate technology diffusion across ~139 plants under different carbon price trajectories

## Run
```bash
pip install streamlit numpy pandas plotly
streamlit run app.py
```
